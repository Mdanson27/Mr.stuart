# Mr. Stuart — Smart Digital Business Profile

Premium responsive digital business card for **Stuart Sengonzi Sebunya**, Business Development Lead & Head of Diaspora Engagement at Honest Estate Developers Ltd.

## Required image files

Place these two files in the repository root using these exact lowercase names:

- `picture.png` — Stuart's profile photo
- `logo.png` — Honest Estate Developers logo

The site already references both files and includes graceful visual fallbacks until they are added.

## Profile structure

1. Executive hero — identity, company, calls, WhatsApp, email and Save Contact
2. Profile & leadership — professional summary, competencies and roles
3. Connect — high-impact CTA plus AutoMinds Africa designer footer

## Features

- Premium light, bright corporate visual direction
- Approximately three-section / three-scroll experience
- 2.1 second animated branded opening loader
- Responsive desktop and mobile layout
- Downloadable `.vcf` vCard contact
- Direct call, WhatsApp and email actions
- LinkedIn connection action
- `Made by AutoMinds Africa` signature treatment
- Image fallbacks when `picture.png` or `logo.png` are not yet present

## Run locally

Open `index.html` directly in a browser or serve the folder with any static development server.

## Deploy

This is a static site and can be deployed directly to Netlify, GitHub Pages, Cloudflare Pages or any static host.
